### T0.1 scope (from the plan, `docs/plans/PLAN_recipe_app_foundation.md` line 557)
Toolchain + project skeleton:
- A simple **GNU Makefile** (no CMake, no vcpkg) that pins **C++20** and finds the system
  libs via `pkg-config --cflags --libs libpq openssl libutf8proc`.
- The `/backend` layout: `/lib` (`/net /router /json /jsonschema /db /httpclient`) + `/app`
  + `/tests` (D1), plus a Catch2 test target.
- A **`make asan`** target (`-fsanitize=address,undefined`) that runs the Catch2 suite —
  the key safety net for the four hand-rolled untrusted-input parsers. TSan config too (it
  later covers the T0.9 thread pool + T0.6 db pool).
- Stand up the **dev `docker-compose` Postgres** service (pulled forward so all of M0 can
  talk to a DB).

**Done when (Verify):** `make` builds; a trivial Catch2 test passes green **under ASAN+UBSAN**
(`make asan`); the dev Postgres container comes up.

**Why Make not CMake:** build is Linux-only (WSL2 dev, Linux deploy), so CMake's
cross-platform value doesn't apply; a hand-written Makefile keeps compile/link visible,
which suits the learn-the-fundamentals goal.
